# AI development disclosure

This project was “vibe-coded” with OpenAI Codex.

## What that means

- The project owner supplied the original idea, functional requirements, EDCoPilot documentation and example files, testing feedback, feature choices, and release decisions.
- OpenAI Codex generated and revised most of the source code, automated tests, build configuration, and documentation through an iterative conversation with the project owner.
- The project owner manually exercised the application, identified failures, supplied real EDCoPilot time trials, and requested corrections and additional features.
- Automated tests and compatibility fixtures were created during development, but they do not prove that the application is free of defects.

The intention of this disclosure is to describe the development process plainly—not to imply that AI-generated code is inherently correct or that the project received an independent security audit. Users and contributors are encouraged to inspect the source, report problems, and submit improvements.

This is an unofficial community project. It is not affiliated with or endorsed by OpenAI, Frontier Developments, Elite Dangerous, or EDCoPilot.
